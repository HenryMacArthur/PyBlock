# LiberPy

PyBricks is a great way to use MicroPython with robotics, but to use their blocks and not just their text, you have to pay, either for a subscription or a license. So, LiberPy (I had no idea what else to call it) provides PyBricks blocks that anyone can use and understand, much like SPIKE Prime, and all for free. It's better than SPIKE Prime because it compiles to MicroPython, so it runs <i>WAY</i> faster, it's got built in gyro, and it's open-source (because open-source is always the G.O.A.T.)

# Usage

It's pretty simple. Drag block, upload code, press button, yay.
