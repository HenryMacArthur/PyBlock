# PyBlock

PyBricks is a great way to use MicroPython with robotics, but to use their blocks and not just their text, you have to pay, either for a subscription or a license. So, PyBlock provides PyBricks blocks that anyone can use and understand, much like SPIKE Prime, and all for free. It's better than SPIKE Prime because it compiles to MicroPython, so it runs <i>WAY</i> faster, it's got built in gyro, and it's open-source (because open-source is always the G.O.A.T.)

# Usage

It's pretty simple. Drag block, upload code, press button, yay.

Right now, we haven't got SPIKE blocks working yet, but once we do, you can paste the generated Python into the PyBrick editor. We will also work on getting this thing to connect to the robot without needing the PyBricks editor.

# Notes

This currently is not usable for actual robotics.

IMPORTANT: You can't run this by just opening the HTML file; it has to be ran through a localhost server.
